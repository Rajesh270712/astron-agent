# 設定と認証 FAQ

## ログイン後もログインページでループしたり、localhost にリダイレクトされる場合

1. Casdoor の設定: Casdoor の `origin` と `redirect_uri` は、ブラウザでアクセスするアドレスと一致している必要があります。
2. Casdoor 管理画面: Casdoor 管理画面（デフォルトポート 8000）にログインし、Application のコールバックアドレス設定を確認します。

## デフォルトのアカウントとパスワードは何ですか？

- Casdoor（管理画面）: アカウント `admin`、パスワード `123`。
- Ragflow: ユーザー自身でアカウントを登録する必要があります。

## Casdoor は HTTPS をサポートしていますか？

現在、Astron に内蔵されている Casdoor 設定は直接 HTTPS を有効にする場合に対応していない可能性があります。Casdoor サービスの前に Nginx リバースプロキシを追加して SSL/HTTPS 暗号化を処理することをお勧めします。

## アプリケーションの作成に失敗し、ログに 403 エラーが表示される場合

403 は通常、権限または認証の問題です。環境変数設定（API Key、Secret など）が正しく入力され、デプロイドキュメントの要件と一致しているか確認してください。

## IP アドレスまたはポート設定を変更しても反映されない場合

`.env` ファイルまたは `docker-compose.yaml` の環境変数を変更した後、コンテナを再起動するまで反映されません：`docker compose down` してから `docker compose up -d` を実行してください。

## クライアントで組織を切り替えることはできますか？

はい、可能です。クライアントのログインは Casdoor 認証に基づいています。認証付きデプロイガイドを参照し、Casdoor 管理ページで組織とユーザーを設定してください。
